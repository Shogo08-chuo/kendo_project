# 技術評価向けガイド

このリポジトリで特に見てほしい点を、短時間で確認できるように整理したものです。

## 1. 課題設定

剣道の試合分析では、打突動作が高速であるため、動画を目視で確認して技の傾向を集計する作業に時間がかかります。本プロジェクトでは、画像認識と動画フレーム解析を組み合わせ、面・小手・胴の発生回数を自動集計するプロトタイプを実装しました。

## 2. 技術的に工夫した点

- AWS Rekognition Custom Labelsを利用し、競技特化の画像分類モデルとして剣道技を推論
- OpenCVで動画から一定間隔のフレームを抽出し、静止画推論として扱う構成にした
- 同一打突が連続フレームで重複カウントされる問題に対し、技ごとの時間窓で重複排除した
- Streamlit UIと推論・集計・DB処理を分離し、CLIやテストからも再利用できる構成にした
- AWSモデルARNや認証情報をSecrets/環境変数へ外部化し、提出時の情報漏えいを防いだ
- 外部APIを使わない単体テストを追加し、重複排除・設定読み込み・DB保存を検証可能にした

## 4. 今後の発展性

現状はプロトタイプとして「一定間隔のフレームを分類する」方式を採用しています。今後は、データセット拡充、評価指標の導入、YOLOや姿勢推定との組み合わせ、S3/SQS/Lambda等を用いた非同期解析に発展させることで、より実運用に近い構成へ拡張できます。
