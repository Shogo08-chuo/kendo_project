# 評価・改善計画

## 評価したい指標

| 指標 | 目的 |
| --- | --- |
| Precision | 検出した技が実際に正しいかを確認する |
| Recall | 実際に発生した技をどれだけ取り逃さず検出できたかを確認する |
| F1-score | PrecisionとRecallのバランスを見る |
| False Positive数 | 誤検出が実用上許容できるかを確認する |
| False Negative数 | 重要な打突の取り逃しを確認する |
| 処理時間 | 試合動画1本あたりの解析時間を確認する |

## 検証データの作り方

1. 個人が特定されない、または公開・利用許諾を得た動画のみを使う
2. 動画を数秒単位のクリップに分割する
3. 各クリップに`men`、`kote`、`do`、`none`のラベルを付ける
4. 撮影角度、照明、距離、選手の体格差が偏らないようにする
5. 学習用、検証用、テスト用に分け、テスト用動画は最後まで学習に使わない

## 改善の優先順位

### 1. データセット拡充

現状の最大の制約は競技特化データの少なさです。まずは面・小手・胴それぞれのサンプル数を増やし、撮影環境のばらつきを含めます。

### 2. 重複排除ロジックの改善

現在は同一技を時間窓で除外しています。今後は、検出信頼度のピークを1つのイベントとして扱う方法や、直前後のフレームをまとめて1打突として扱う方法に改善できます。

### 3. モデル方式の比較

Rekognition Custom Labelsに加えて、YOLO系の物体検出、MediaPipeなどの姿勢推定、時系列モデルを比較し、剣道の高速動作に適した方式を検証します。

### 4. 非同期処理化

長時間動画では解析に時間がかかるため、S3へアップロード後にキューで解析ジョブを実行し、完了後に結果をDBへ保存する構成へ発展できます。
